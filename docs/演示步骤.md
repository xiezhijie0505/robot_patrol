# 板端演示步骤（V1）

仓库在 Windows 改；**跑起来在 RK3568**。先 `scp` 整个 `robot_patrol` 到板子，例如 `/root/robot_patrol/`。

## 只有一个终端：一条命令

```sh
# 1) 小车放到矩形起点
# 2) SSH 登录 RK 后：
cd /root/robot_patrol
chmod +x scripts/*.sh alarms/scripts/*.sh detect/scripts/*.sh streaming/scripts/*.sh
sh scripts/start_all.sh
```

会：后台 **alarms** + 自动发 **PATROL START**（找到串口时）+ 前台 **多线程 YOLO**（默认同时推流）。

- 浏览器查报警：`http://<板子IP>:8080/`
- VLC 看画面：`rtsp://<板子IP>:8554/cam`

不必再单独用手发开始码。串口找不到时：`export CHASSIS_UART=/dev/ttyS3` 再运行。

可选：

```sh
START_PATROL=0 sh scripts/start_all.sh    # 不起步巡逻
ENABLE_STREAM=0 sh scripts/start_all.sh   # 检测但不推流
START_RTSP_ONLY=1 sh scripts/start_all.sh # 仅旧版推流
```

结束：前台 `Ctrl+C`；再 `sh scripts/stop_all.sh`。

STM32 固件仍须 Keil 单独烧录。推流线程依赖 OpenCV 带 GStreamer；若 `VideoWriter` 失败，设 `ENABLE_STREAM=0` 仍可抓拍。

### 和 DMS 怎么区分（面试）

| 项目 | 并发模型 |
|------|----------|
| DMS | 多进程 + 共享内存 |
| 本巡逻 `detect/` | **多线程**：生产者-消费者队列 + 告警线程池 + 推流消费最新帧 |

## A. 远程看画面（已打通）

```sh
cd /root/robot_patrol/streaming
sh scripts/start_rtsp.sh
```

电脑 VLC：`rtsp://<板子IP>:8554/cam`

> 推荐用多线程检测进程同时推流（`ENABLE_STREAM=1`）。旧脚本 `streaming/scripts/start_rtsp.sh` 会独占摄像头，不要和检测同时开。

## B. 底盘巡逻 + 防撞 + 烟雾

1. Keil 编译下载 `firmware/stm32_chassis`  
2. 对照 `docs/硬件接线.md`  
3. 电脑串口（或 RK 串口）：

```text
PATROL START
PATROL STOP
```

矩形约 2.0×1.2 m，时间不准改 `chassis_patrol.c` 里 `PATROL_*_MS`。

烟雾触发：蜂鸣 + 停车 + 串口 `EVT SMOKE`。  
RK 上可另开：

```sh
# 先起 alarms
cd /root/robot_patrol/alarms && sh scripts/start_alarms.sh
python3 tools/uart_alarm_bridge.py /dev/ttyUSB0
```

## C. 陌生人 YOLO 抓拍 + 网页查询

1. 准备 `detect/models/yolov5s.rknn`（见 `detect/models/README.md`）  
2. 板端编译 `detect`（见 `detect/README.md`）  
3. 一键：

```sh
cd /root/robot_patrol
sh scripts/start_demo_detect.sh
```

电脑浏览器：`http://<板子IP>:8080/` 看 `stranger` 记录和图片。

V1「陌生人」= YOLO 检测到 **person** → **只抓拍报警，不停车**（未做人脸底库；以后可接 DMS 人脸）。
