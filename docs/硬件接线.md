# 硬件接线（V1 默认，不对就改代码里的宏）

## 已占用

| 功能 | 引脚 |
|------|------|
| USART1 TX/RX | PA9 / PA10（常见） |
| TB6612 PWMA/PWMB | PA6 / PA7（TIM3） |
| TB6612 方向+STBY | PB12–PB15, PB8 |

## 新增默认（可改）

| 模块 | 信号 | 默认脚 | 改哪里 |
|------|------|--------|--------|
| HC-SR04 | TRIG | **PA0** | `chassis_ultra.c` |
| HC-SR04 | ECHO | **PA1** | 同上 |
| 烟雾 DO | 数字输出 | **PA2** | `chassis_smoke.c`（默认低电平=有烟） |
| 蜂鸣器 | 高电平响 | **PA3** | 同上 |

若你的烟雾模块是 **高电平报警**，在 `chassis_smoke.h` 把 `CHASSIS_SMOKE_ACTIVE_LOW` 改为 `0`。

防撞距离阈值：`chassis_ultra.h` 里 `CHASSIS_ULTRA_STOP_CM`（默认 25 cm）。

## 请你确认

把实际接线对照上表；若不一致，告诉我正确引脚，或直接改对应 `.c` 顶部宏后重新编译下载。
